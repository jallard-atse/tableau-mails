Configuration requise

Cette page doit être reliée à votre espace Microsoft 365 avant la première utilisation.

Ouvrez le fichier dans un éditeur de texte et remplacez, au début de la section <script> de configuration :

CLIENT_ID par l'« ID d'application (client) »
TENANT_ID par l'« ID de l'annuaire (locataire) »

Ces deux valeurs figurent dans Microsoft Entra ID après la déclaration de l'application. Le guide d'installation fourni avec ce fichier détaille chaque étape.
